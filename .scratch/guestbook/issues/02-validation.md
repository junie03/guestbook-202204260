# 02: 입력값 검증과 칸별 안내

**What to build:** 이름·메시지·글 비밀번호가 규칙에 맞지 않으면 Entry가 저장되지 않고, 문제가 있는 칸 아래에 안내 문구가 뜨며 입력한 내용은 그대로 남는다. 규칙은 서버(도메인 모듈)에서 검사하므로 폼을 거치지 않아도 똑같이 거부된다. 스펙: [spec.md](../spec.md) (User Stories 5–9, 11)

**Blocked by:** 01 (글 남기기와 목록 보기)

**Status:** ready-for-agent

- [ ] `create`가 규칙 위반 시 예외 대신 칸별 검증 오류를 돌려주고 아무것도 저장하지 않는다
- [ ] 테스트: 이름 0/1/20/21자, 메시지 0/1/500/501자, 비밀번호 3/4/30/31자 경계값
- [ ] 테스트: 공백만 입력한 이름·메시지는 빈 값으로 거부되고, 앞뒤 공백은 지워져 저장된다
- [ ] 테스트: 한글 한 글자를 1자로 센다 (예: 한글 20자 이름 허용, 21자 거부)
- [ ] 테스트: 비밀번호는 공백을 지우지 않는다
- [ ] 화면: "이름은 1~20자로 입력해 주세요." / "메시지는 1~500자로 입력해 주세요." / "비밀번호는 4~30자로 입력해 주세요."가 해당 칸 아래에 뜬다
- [ ] 화면: 거부되어도 입력한 이름·메시지·비밀번호가 폼에 남아 있다
