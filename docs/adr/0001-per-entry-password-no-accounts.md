# v1은 계정 없이 글마다 따로 정한 글 비밀번호로만 수정·삭제 권한을 확인한다

방명록에는 회원가입과 로그인이 없고, 글쓴이가 글을 남길 때 정한 글 비밀번호가 그 글을 수정·삭제할 수 있는 유일한 권한이다. 비밀번호는 Node 내장 `crypto.scrypt`와 글마다 다른 솔트로 해시해서 저장하며, 원문은 어디에도 남기지 않는다. v1에서는 비밀번호를 여러 번 틀려도 시도 횟수를 제한하지 않는다. 짧은 비밀번호는 무차별 대입으로 뚫릴 수 있다는 것을 알고도, 수업용 미니 방명록의 단순함을 우선한 트레이드오프다. 글 비밀번호를 잊으면 그 글은 누구도 고치거나 지울 수 없으며, 이를 대신 처리할 관리자 기능도 두지 않는다.
